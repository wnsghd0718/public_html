# 박준홍 포트폴리오

배포 주소: https://aismartwork20212954.netlify.app

- index.html : 페이지 본문 (첫 화면, 관심 분야, 실적 그래프, 프로젝트, 작업 방식, 소개, 연락)
- 404.html : 없는 주소로 들어왔을 때 보이는 페이지
- css/style.css : 디자인 (어두운 테마 기본, 밝은 모드, 모바일 메뉴, 인쇄용)
- js/projects.js : 프로젝트 목록과 제작 과정 내용 (새 프로젝트는 여기에 { ... } 하나 추가)
- js/main.js : 카드 그리기, 제작 과정 창, 보고서·발표자료 넘겨 보기, 영상 팝업, 메뉴, 숫자 애니메이션
- js/chip.js : 첫 화면의 HBM 칩 그림
- assets/ : 이미지, 영상, 보고서·발표자료(PDF/원본), 넘겨 보기용 쪽 이미지
- ebook-hbm/ : HBM 전자책 리더
